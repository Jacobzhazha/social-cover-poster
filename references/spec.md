# poster.json 格式

一个 JSON 文件，最外层有 `size`、`pages`，可选 `signature`。键名用英文，内容用中文。

```json
{
  "size": "3:4",
  "pages": [
    {"type": "cover", "title": ["第一行", "第二行", "第三行"], "subtitle": "辅助小字",
     "visual": {"scene": "一个场景描述", "text": ["图里的字"], "image": "ImageGen 返回的图片路径"}},
    {"type": "content", "title": ["内页标题", "第二行标蓝"], "points": [{"label": "谁有", "text": "一句话"}]}
  ]
}
```

## 顶层

| 字段 | 必填 | 说明 |
|---|---|---|
| `size` | 否 | `3:4`（默认，1080×1440）、`1:1`（1080×1080）、`16:9`（1920×1080）、`2.35:1`（1800×766）、`9:16`（1080×1920），或 `宽x高`（300–4000 像素） |
| `pages` | 是 | 页面列表，1–18 页。多页时自动加页码 |
| `signature` | 否 | 落款，如 `@账号名`，20 字以内，显示在每页右下角。用户没要求就不写 |

## 封面 `"type": "cover"`

| 字段 | 必填 | 说明 |
|---|---|---|
| `title` | 是 | 1–3 行，每行一个字符串。横图（16:9、2.35:1 等）配场景图或用户图片时最多 2 行 |
| `highlight` | 否 | 标蓝的行号，默认 2（只有 1 行时默认不标蓝），0 表示不标蓝 |
| `subtitle` | 否 | 辅助小字，30 字以内，左侧带黄竖线 |
| `visual` | 否 | 主视觉，三种写法见下表。不写就是纯大字封面 |
| `panel` | 否 | 图标版的底色：`blue`（默认）、`black`、`yellow`、`paper`（浅米色）。场景图和用户图片不加底板，这一项不起作用 |

### `visual` 的三种写法

| 写法 | 什么时候用 | 效果 |
|---|---|---|
| `{"scene": "...", "text": [...], "image": "..."}` | 默认。生成 3D 玩具风场景图 | 不加底板，铺满主视觉区。竖版和方图在上方；横图在标题右边铺到画布边，左缘渐变过渡 |
| `{"image": "图片路径"}` | 用户给了截图、产品图、照片 | 不加底板，放在暖白底上；默认 `contain` 完整显示，可加 `"fit": "cover"` 铺满裁切 |
| `{"icon": "图标名"}` | 用户不要生图，或者没有生图工具 | 图标放在彩色底板上（`panel` 选底色），画面比场景图简单 |

场景图的三个字段：

| 字段 | 必填 | 说明 |
|---|---|---|
| `scene` | 是 | 中文写这一篇演什么小场景，80 字以内。写法见 `references/writing.md` |
| `text` | 否 | 图里要出现的字，最多 4 处，如 `["DeepSeek", "13分"]`。会写进生图提示词要求照写，也计入这一页的字数。不写就是图里不出现任何字 |
| `image` | 出图时必填 | ImageGen 生成的图片路径（相对 poster.json 或绝对路径）。先不写，运行 `--prompts` 拿参数、生图之后再填 |

`--prompts` 会按这一页主视觉区的实际大小选生图尺寸（1536x1024、1024x1024 或 1024x1536 之一），并在提示词里写明哪部分会被裁掉。排版时图片铺满并对齐右下角：竖版只裁上边，横版只裁左边，右下角的「AI生成」标识始终保留。

竖版和方图：主视觉在上、标题在下。横图：标题在左、主视觉在右。

## 内页 `"type": "content"`

| 字段 | 必填 | 说明 |
|---|---|---|
| `title` | 是 | 1–2 行，第 2 行自动标蓝 |
| `lead` | 否 | 导语，50 字以内，灰色 |
| `badge` | 否 | 蓝色色块里的大字：`{"main": "11月4日", "note": "美西时间"}`。main 12 字以内，适合放日期、价格、数字；note 10 字以内，可省略 |
| `points` | 否 | 要点，最多 3 条。`{"label": "谁有", "text": "..."}`，label 6 字以内、可省略；也可以直接写字符串 `"一句话"` |

内页除了标题，至少要有 `lead`、`badge`、`points` 其中一项。每页所有文字加起来不超过 120 字。

## 常见报错怎么改

| 报错里写着 | 怎么改 |
|---|---|
| 某一行「太长」 | 按提示的字数缩短这一行，或把它拆到另一行（封面最多 3 行） |
| 主视觉区被挤得太小 | 减少一行标题，或去掉 subtitle |
| 写了 scene，但还没有生成图片 | 先加 `--prompts` 运行，按给出的参数调用 ImageGen，把图片路径填进 visual.image |
| 横版封面配场景图或图片时，标题最多 2 行 | 把三行合并或精简成两行，细节挪到 subtitle |
| visual.scene 场景描述最多 80 个字 | 只留一个动作和必须出现的东西 |
| 生成图和主视觉区比例差得多（提醒） | 打开 PNG 看主体是否完整；不完整就按 `--prompts` 给的 size 重新生成 |
| 内容太多，竖向放不下 | 删一条要点，或去掉 lead / badge，或把每条要点写短 |
| 超过 2 行 | 把这条要点或导语缩短到提示的字数以内 |
| 文字共 N 个字，上限 120 | 删掉重复和次要信息，必要时拆成两页 |
| 不是合法的 JSON | 检查逗号、引号、括号；最后一项后面不要逗号 |
